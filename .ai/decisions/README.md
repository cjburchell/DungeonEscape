# Decision records

Reserved for explicit architectural/workflow decisions. No historical ADRs have been reconstructed
for AI-001; rationale and approval dates cannot be inferred from code alone.

Existing history and ongoing choices remain in the [memory bank](../../memory-bank/README.md).
Record a new decision when a task actually makes one, linking its issue or approval evidence.

Suggested record format (a workspace convention, not a claim of previous practice):

- Filename: `NNNN-short-topic.md`.
- Status: proposed, accepted, superseded or rejected; date only when known.
- Context/problem and evidence links.
- Decision and considered alternatives.
- Consequences, validation and unresolved unknowns.
- Approval/source reference; link the superseding record if applicable.

Do not mark a proposal accepted without supporting authorization. Never invent missing history.
